# SG Forester Amber Auxiliary Light Kit

3D-printed amber auxiliary light housings and retainers that flush-mount into the
fog light openings of the **2006–2008 Subaru Forester Sports bumper (SG facelift)** —
a clean, factory-like install with fully adjustable beam aim.

![Assembled housings](gallery/hero_housings.jpg)

Designed, sold, and street-proven by SMITHTRONIC in 2024–2025 (as $250 assembled /
$150 DIY kits); now open source under CC BY-NC-SA 4.0.

## What it is

- **Housing (left + right)** — fills the bumper's fog opening and carries any
  single-through-bolt light (bracket up to 64.5 × 23 mm) with vertical and
  horizontal articulation.
- **Retainer (left + right)** — clamps the housing from behind the bumper via 6
  brass M3 heat-set inserts and stainless button-head bolts. Embossed with
  side and "Towards Engine" orientation marks.
- Wired into the **factory fog light circuit** using the OEM relay (82501AE03A)
  and dash switch (83001SA000) — the harness is already in the car.

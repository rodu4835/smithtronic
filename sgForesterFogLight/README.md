# SG Forester Amber Auxiliary Light Kit

3D-printed fog light housings and retainers for the 2nd-generation (SG, 2003–2008)
Subaru Forester, filling the factory fog light openings in the bumper with amber
auxiliary LED pods.

<!-- TODO(CP4): hero image -->

Formerly sold as a kit by SMITHTRONIC; now open source.

## Parts

| Part | Qty | Material | Notes |
|---|---|---|---|
| Housing (left, right) | 1 each | ASA | fills the bumper fog opening, holds the light |
| Retainer (left, right) | 1 each | ASA | clamps the housing from behind the bumper; takes brass M3 heat-set inserts |

Left/right refers to the side of the car as seated in it (US driver side = left).
